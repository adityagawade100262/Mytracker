# 📊 MyTracker

A modern and responsive personal expense tracker built using **HTML, CSS, and JavaScript**. MyTracker helps users record daily income and expenses, organize transactions by month, search records, edit or delete entries, and securely store data in the browser using Local Storage.

---

## 📌 Overview

MyTracker is a lightweight finance management application designed to help users keep track of their daily transactions without requiring an account or internet connection. All data is stored locally in the browser, making the application fast, private, and easy to use.

---

## ✨ Features

- 💰 Add Income and Expense transactions
- 📅 Select transaction date
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 🔍 Search transactions by description
- 📆 Monthly transaction filtering
- 📊 Dashboard displaying:
  - Total Income
  - Total Expenses
- 💾 Local Storage support (data remains after browser refresh)
- 🌙 Automatic Dark Mode support
- 🎨 Modern Glassmorphism UI
- 📱 Responsive design for desktop and mobile
- 💸 Automatic emoji icons based on transaction type (Tea, Petrol, Salary, Food, etc.)
- ✅ Input validation before saving

## 💡 How It Works

1. Select the transaction date.
2. Enter the description.
3. Enter the amount.
4. Choose either:
   - Credit (Income)
   - Debit (Expense)
5. Click **Save Transaction**.
6. Transactions are automatically stored in Local Storage.
7. View transactions month-wise.
8. Search any transaction using the search box.
9. Edit or delete transactions whenever needed.

This project uses the browser's **Local Storage** to save transaction data.

- No database required
- No internet connection required
- Data remains after refreshing the page
- Data is stored only on the user's device
